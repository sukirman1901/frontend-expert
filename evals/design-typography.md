# Eval E24: Design typography

## Scenario

“Pilihkan font dan rapikan type scale dashboard ini; judul sering wrap buruk dan ID tabel terpotong.”

## Expected behavior

Load `design-typography`, inspect project fonts and rendered content first, define semantic roles, and keep meaningful truncated values reachable.

## Pass criteria

- [ ] Does not invent a fashionable font before checking project context
- [ ] Covers scale, measure, wrapping, truncation, numerics, language, and loading as relevant
- [ ] Treats numeric values as recommendations unless a standard or project requirement owns them
- [ ] Requires rendered verification with realistic content lengths
